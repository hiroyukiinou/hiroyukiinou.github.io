# ブラウザ音取りキーボード 仕様案

## 1. 目的
Mac と iPad のブラウザで使える、音取り・音程確認用の鍵盤アプリを作る。インターネット接続なしでも主要機能を使え、必要な音をすぐ鳴らせることを重視する。

## 2. 想定ユーザーと利用場面
- 歌や楽器の練習前に、最初の音・基準音を確認したい人
- 音程や和音を耳で確認したい人
- Mac のマウス／トラックパッド、物理キーボード、または iPad のタッチ操作で鍵盤を弾きたい人
- 楽譜を見ながら、基本は一つのパートの単旋律を弾いて音取りしたい人

聴音テストやソルフェージュ練習は対象にしない。

## 3. 対応環境
- Mac および iPad の主要ブラウザ（Safari を優先）
- Web Audio API 対応ブラウザ
- 画面幅に合わせてレイアウトを調整するレスポンシブ UI
- インストールなしでも利用可能。オフライン利用のため、初回読み込み後にホーム画面へ追加できる PWA として提供する
- 横長画面では鍵盤を上下 2 段に表示する。上下段の鍵域は連続させ、全体として広い音域を見渡せるようにする
- 縦長画面では操作性を優先し、鍵盤を1段表示して横スクロールまたはオクターブ移動で音域を選ぶ

## 4. MVP 機能

### 4.1 鍵盤
- 画面内に少なくとも 2 オクターブ分の鍵盤を表示する
- 白鍵・黒鍵をタップ／クリックして発音する
- 押している間は発音し、離すと減衰して止まる
- サスティンペダルがオンの間は、鍵を離しても音を伸ばす。オフにすると離鍵済みの音を止める
- iPad では複数鍵を同時に押せる（ポリフォニー）
- Mac の物理キーボードからも音を入力できる。ホームポジション付近に白鍵を割り当て、隣接キーで黒鍵を弾く方式を初期案とする
- 物理キーボードの入力範囲、現在のオクターブ、割り当てを画面上で確認できる。オクターブ変更キーを用意する
- オクターブ移動操作を備える
- オクターブ移動とは独立した、半音単位のトランスポーズ操作を備える。現在の移調量（例：+2 semitones）を表示し、0 に戻せる
- 音名を鍵盤に表示する設定を備える
- サスティンペダルは画面上の切り替えボタンとして操作できる。Mac では任意で Space キー等のショートカットも検討する

### 4.2 音色と音量
- 初期音色は、音取りに適した柔らかい持続音とする
- ピアノのような急な減衰音ではなく、鍵を押している間に安定して鳴り続ける
- 純音より適度に倍音を含ませ、音程を識別しやすくする
- 高域の強い倍音や鋭いアタックを抑え、キラキラしすぎない音にする
- 音色候補は「柔らかいオルガン／リード系シンセ」を初期案とし、実装時に試聴して調整する
- 音量調整を備える
- 音色の切り替えは初期版では必須にせず、後から追加可能な構成にする

### 4.3 音取り（基準音）
- 音名を選んで基準音を鳴らせる
- 基準音はボタン操作で繰り返し再生できる
- 基準ピッチ（A4）を変更できる。初期値は A4 = 440 Hz とし、A4 = 415 Hz などのプリセットと任意の Hz 入力を用意する
- 音取り向けに、音を一定時間保持する／繰り返し鳴らす操作を用意する

### 4.4 音律
- 平均律と純正律を切り替えられる
- 純正律では主音（キー）を選択できる（手動選択は必須）
- MVP の純正律は長調・短調を対象とし、各音の周波数比を主音に対して決める
- 純正律を選んだとき、現在の主音と音律が画面上で分かる
- 和音に応じた自動調整は望ましい拡張機能とするが、初期版では必須にしない
- 自動調整を追加する場合は、同時に鳴っている音から和音を推定して音程を調整する。調整結果は不意に変わらないように表示または設定可能にする

### 4.5 操作補助
- サスティンペダルのオン／オフを画面上で分かりやすく表示する
- ブラウザの音声再生制限に対応し、最初のユーザー操作後に音を有効化する
- 音声出力がミュート／利用不可の場合に、簡潔な案内を表示する

## 5. オフライン要件
- アプリ本体と必要な音源・音声生成処理を初回利用時にキャッシュする
- 2回目以降はネット接続なしで起動し、鍵盤・音取り・音律切り替えを使える
- アプリの主要機能に外部 API、ログイン、広告配信を必要としない
- オフライン利用の保証範囲は「少なくとも一度オンラインで開いた後」とする

## 6. 純正律の初期仕様（仮）
- 初期版では、主音を手動で選ぶ「主音固定の5-limit純正律」を採用する
- 長調の基本比率は主音から 1/1, 9/8, 5/4, 4/3, 3/2, 5/3, 15/8, 2/1 とする。短調の基本比率は主音から 1/1, 9/8, 6/5, 4/3, 3/2, 8/5, 9/5, 2/1 とする
- 主音の周波数は選択した主音の平均律上の周波数を基準にし、そこから比率で音階を作る
- 主音を変更すると音階全体を再計算する
- この方式は単旋律の音取りに分かりやすい一方、異名同音（例：C♯とD♭）を同じ鍵にまとめる通常の鍵盤では、全調・全和音を同時に純正にできない。転調や臨時記号の多い楽譜では、主音固定の音律が意図と合わない場合がある
- 和音ごとに比率を変える自動調整は初期版の対象外。後続版で方式を検討する

※「純正律」は運用方法に複数の流儀があるため、比率表と転調時の扱いは実装前に確定する。

## 7. 画面構成
- 上部：音律、主音、長調／短調、基準ピッチ（A4）、トランスポーズ
- 中央：鍵盤。横長では上下 2 段、縦長では1段
- 下部またはサイド：音名／オクターブ移動、音量、サスティンペダル
- iPad はタッチしやすい大きな操作部品を配置する
- Mac は横幅を活かし、鍵盤と設定を同時に見やすくする
- Mac では物理キーボードの鍵盤割り当てとオクターブを表示する

## 8. 非機能要件
- 初回操作から音が出るまでの待ち時間を短くする
- 画面回転・サイズ変更に追従する
- 視認性の高い配色と、鍵盤以外の操作にも十分なタップ領域を確保する
- 音名表記は英語音名（C, C♯, D…）を初期値とし、表記方式の切り替えは後で検討する

## 9. MVP の対象外
- マイク入力による音程解析・チューナー
- 聴音テスト、音感クイズ、ソルフェージュ練習
- 録音、再生履歴、曲やプリセットの保存
- MIDI 入出力
- 楽譜の表示・読み込み・自動演奏
- 複雑な歴史的音律、微分音、任意の音律編集
- 和音を検出してリアルタイムに純正律へ追従する機能（望ましい拡張だが初期版では必須でない）

## 10. 受け入れ条件
- Mac と iPad のブラウザで鍵盤を操作して音が出る
- 横長画面では鍵盤が上下 2 段になり、縦長でも主要操作が使える
- 音名を選んで単音の基準音を再生できる
- A4=440 Hz と A4=415 Hz などの基準ピッチを選べ、任意の基準周波数も設定できる
- 半音単位のトランスポーズを設定でき、オクターブ移動とは別に動作する
- Mac の物理キーボードで割り当てた音を発音でき、オクターブを切り替えられる
- 平均律／純正律を切り替え、純正律の主音と長短を手動で選べる
- iPad で複数鍵を同時に押して和音を鳴らせる
- サスティンペダルをオンにして離鍵後も音を保持し、オフで止められる
- 一度読み込んだ後、オフラインでも主要機能が動作する
- 持続音が音取りに使いやすく、過度に鋭い・明るい倍音にならない

## 11. 実装上の前提
- 音は Web Audio API による合成を第一候補とし、音源ファイルへの依存を減らす
- 音色は複数の発振器を混ぜ、倍音量とアタック／リリースを調整して作る
- オフライン化は Service Worker と Web App Manifest を使う
- まずは単一ページの軽量な Web アプリとして構成する

## 12. 残る決定事項
1. 横長画面の上下2段鍵盤は、上下段で連続する音域を表示する案を採用（仮）
2. 純正律の具体的な比率表と、主音を基準に各音を割り当てる方式
3. 初期音色の試聴・調整。柔らかいオルガン／リード系を出発点にする
4. トランスポーズは鍵盤表示・物理キーボード入力・発音のすべてに適用し、純正律では移調後の主音を基準に音階比率を適用する
5. 基準ピッチは選んだ音律の周波数基準を変更する。純正律の主音周波数もこれに追従する
6. Mac の物理キーボード配列とオクターブ切り替えキー
