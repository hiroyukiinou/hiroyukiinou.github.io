# 音取りキーボード

## 使い方
`index.html` をブラウザで開くと、鍵盤・基準ピッチ・トランスポーズを試せます。最初に画面をタップまたはクリックすると音声が有効になります。

- 画面の鍵盤をクリック／タップして発音
- Mac の `A W S E D F T G Y H U J K` で1オクターブを演奏
- `Z` / `X` で鍵盤の表示音域を1オクターブ移動
- サスティンをオンにすると、鍵を離しても音を保持
- A4=415 Hz を選ぶとバロックピッチ
- 横長表示では鍵盤を上下2段で表示

## オフライン利用
PWA としてオフライン起動する場合は、このフォルダ一式を HTTPS の静的ホスティングに置き、オンライン時に一度開いてください。その後、ブラウザの「ホーム画面に追加」または「アプリをインストール」から追加すると、キャッシュ済みのアプリをオフラインで起動できます。音の合成はブラウザ内で行い、外部音源や API は使いません。

## 現在の試作範囲
- 平均律／主音固定の5-limit純正律（長調・自然短調）
- 音律、主音、A4 基準ピッチ、半音トランスポーズ
- 合成した持続音、ポリフォニー、サスティン
- Mac の物理キーボード入力
- Service Worker によるアプリ資材のキャッシュ

臨時記号は近似的に割り当てています。和音に応じて音程を自動調整する機能、MIDI、楽譜表示、音程解析は含みません。
